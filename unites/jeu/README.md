# Atelier des unités

Cours interactif (pas une évaluation).  
**Site :** https://sroddier.github.io/diagnostic-bts-ms/unites/jeu/

6 ateliers (préfixes → géo → méca → cinématique → énergie → ordre de grandeur) puis un **boss** « ligne de 6 h 00 ».

- 4 / 5 pour l’étoile et débloquer la suite
- Boss : 8 décisions, 3 vies, 6 justes pour valider
- Progression dans le navigateur (`localStorage`)
- Le corrigé s’affiche : c’est un cours
