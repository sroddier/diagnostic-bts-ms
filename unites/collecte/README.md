# Collecte — unités et conversions

Même procédure que le positionnement général, **autre feuille**.

1. [Créer une feuille](https://sheets.new) `Unités conversions BTS MS 2026` — **privée**.
2. Extensions → Apps Script → coller `unites/teacher/Code-a-coller.gs` (généré, contient le barème).
3. Exécuter `setup` → autoriser.
4. Déployer : Application web, Moi, Tout le monde.
5. URL `/exec` → `unites/js/config.js`.

Code séance : `UN26R1` (différent de `MS26R1`).
